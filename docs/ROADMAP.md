# Prototype status

This repository is intentionally kept as a prototype. No further product
features or production trading capabilities are planned here.

The current implementation consists of a Next.js dashboard and a single
FastAPI app. The API serves Indian-market chart candles, EMA signals, stock
search, and a small scanner universe.

For local setup and endpoint details, see [README](../README.md) and
[API notes](./API.md).
